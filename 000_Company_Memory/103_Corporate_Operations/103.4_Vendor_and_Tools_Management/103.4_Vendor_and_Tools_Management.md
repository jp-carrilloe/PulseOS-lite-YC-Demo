## 3. Vendor Evaluation Criteria (The "Founder Tool" Test)

Before adopting any new tool, YC asks:
1. **Does it scale?** Can it handle 10,000+ founders without friction?
2. **Is it high-signal?** Does it add value to the founder experience or just create noise?
3. **Can we build it better?** If the tool is core to the founder experience, YC prefers building it in-house.
4. **Is the vendor a YC Alum?** YC prioritizes supporting its own portfolio companies (e.g., Stripe, Gusto, Brex).

## 4. Vendor Offboarding Process
- [ ] Export all data and migrate to internal systems.
- [ ] Revoke admin access via G Suite / SSO.
- [ ] Update the internal "Tool Library" on Bookface if the tool was founder-facing.
- [ ] Document the reason for decommissioning to share as a "lesson learned" with the community.
